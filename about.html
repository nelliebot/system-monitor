🔧 Technical Notes

No LLM Calls - Guaranteed

This dashboard runs zero LLM calls. All data collection is done via shell scripts that read system files directly:

  • Temperature from /sys/class/thermal/
  • Memory from free -h
  • Load average from uptime
  • Process counts from ps aux
  • Agent activity from OpenClaw cron run logs

Correlation Insights

The chart shows temperature, load, and agent activity over time. When agent activity (green dots) correlates with temperature spikes, that shows agents are doing work. Load avg shows overall system demand.

How to Read the Chart

  • Red line: Temperature (°C) - higher = more CPU work
  • Blue line: Load average × 10 (scaled to fit)
  • Green dots: Agent activity (cron runs in last 30 min)
